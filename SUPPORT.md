# Support

Jet Browser is an open-source browser runtime. Choose the channel that matches your request so maintainers and other users can respond with the right context.

## Reproducible defects

Use the [bug report form](https://github.com/masakaai/jet-browser/issues/new?template=bug_report.yml) for a problem you can reproduce in the standalone runtime, JSONL protocol, SDK, native input path, page inspection, or published Agent Skill.

Include the Jet Browser version or commit, host architecture, Docker and Node.js versions, the smallest disposable fixture, exact commands, expected result, observed result, and redacted logs. Search [existing issues](https://github.com/masakaai/jet-browser/issues) first.

## Integration questions

Use [GitHub Discussions Q&A](https://github.com/masakaai/jet-browser/discussions/categories/q-a) for setup questions, harness integration, container restrictions, required browser APIs, or help interpreting verification output.

Jet Browser runs an isolated WPE WebKit session. It does not attach to a personal Chrome profile or provide Chromium extension and CDP compatibility.

## Feature proposals

Use the [feature request form](https://github.com/masakaai/jet-browser/issues/new?template=feature_request.yml) for a focused protocol, SDK, runtime, or documentation change. Explain why the behavior belongs in the runtime rather than the calling harness or an optional control plane.

## Security reports

Do not open a public issue for a vulnerability or include credentials, cookies, profiles, private hostnames, or personal data in any report. Follow the private process in the [security policy](https://github.com/masakaai/jet-browser/security/policy).

## MASAKA managed service

Questions about MASAKA-managed infrastructure, accounts, or service-specific behavior belong in [MASAKA support](https://masaka-ai.vercel.app/docs/support/). The open-source issue tracker cannot access managed-service account data.

Support is community-based and does not guarantee a response time. Public reports should contain only synthetic or safely redacted data.
